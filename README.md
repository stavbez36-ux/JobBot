# JobBot# JobBot — Telegram бот для поиска вакансий

**JobBot** — дружелюбный Telegram-бот, который помогает пользователям находить вакансии и подработки на популярных сайтах: hh.ru, superjob.ru, rabota.ru, LinkedIn, Indeed, fl.ru, youdo.com, kwork.ru, Upwork и других.

---

## ⚡ Особенности

- Быстрый поиск вакансий и подработок
- Поддержка удалённой работы, фриланса и офисных вакансий
- Отображает название вакансии, компанию, зарплату и ссылку
- Поддержка нескольких категорий через кнопки (удалёнка, курьер, дизайнер, менеджер и т.д.)
- Лаконичные ответы с 3–5 актуальными вакансиями за раз
