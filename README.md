# JobBot (RSS версия)

Telegram-бот для поиска вакансий и подработок без использования AI и без лимитов.

---

## 🚀 Что умеет бот

- Показывает вакансии из hh.ru и SuperJob
- Работает через RSS (без API лимитов)
- Категории вакансий через кнопки
- Полностью бесплатный и работает 24/7
